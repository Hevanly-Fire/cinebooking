# **App Name**: CineBook

## Core Features:

- Movie Listings: Display a list of available movies with their posters, titles, and showtimes.
- Similar Movie Suggestions: Suggest similar movies to the current one selected, using a LLM model as a tool for reasoning about similarity of movies based on genre, actors, and keywords.
- Selection Interface: Allow users to select a movie, showtime, and number of tickets, subject to availability.
- Booking Summary: Display a summary of the booking including movie, showtime, number of tickets, and total cost, subject to availability.

## Style Guidelines:

- Primary color: Red (#FF0000) for a bold and dramatic feel.
- Secondary color: Gold (#FFD700) for highlights and accents.
- Background color: Black (#000000) for a sleek and cinematic look.
- Clean and modern layout with clear sections for movie listings, selection, and booking summary.
- Use simple, recognizable icons for navigation and actions (e.g., play, time, tickets).
- Subtle transitions and animations for a smooth user experience.
